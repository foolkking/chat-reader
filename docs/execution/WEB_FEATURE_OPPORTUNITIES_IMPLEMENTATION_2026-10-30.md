### 补齐五项的有界合同（127eae5 已发布）

- 预览复用 `_share_message_query` 与完整轮次 hydration；锚点必须在范围内。
  预览不持久化分享或访问数据；包含私人内容的能力按显式选项展示，不默认分享。
- 对照页不重复挂整个 Reader；每侧自有 conversation/turn 查询与真实 DOM，
  两侧对话必须不同，导航不提交 reading-position。目录复用既有分页组件，
  标题搜索使用 owner 过滤及字面通配符转义，不只查前 200 个对话。
- 标签最多 100、名称 40 字符、每标签最多 2,000 成员，NFKC/casefold 防重，
  目标重查 owner。取消最后一个成员仍保留标签；修改触发相关 offline revision。
  v3 包携带可选只读名称快照，旧 v1/v2/v3、Dexie v2、已有本机数据不被改版覆盖。
- 基线只由显式动作创建／更新，不从 `updated_at` 或阅读位置猜测；最多 100,000
  活跃消息身份，按千条写入并有跨批回归。已见消息编辑不算新增，删除不计数。
- 冻结最多 5,000 消息、5,000 标题、50,000 blocks／24 MiB；先 SQL 预算后 hydrate，
  总序列化大小再次校验。正文、版本、目录与可选说明保存为独立投影；
  暂不支持附件、批注、笔记或访客导出，前后端明确阻止，不伪造永久附件。
  撤销删快照，过期 worker 有界回收，与设置写入行锁串行；回收后不得复活。
  旧实时链接及访问安全合同不变，0058 保留 live 数据库默认以允许旧应用写入。
- 标签、基线和快照均随运维 PostgreSQL 备份；不承诺个人／系统 `.cr` 迁移这些
  新账户配置。应用回退留表，不自动 downgrade；冻结附件永久保留不在此阶段内。
  若已有 frozen Share 行，旧代码不能安全读取；必须保持停写并前向恢复，
  不能仅凭 live 默认值就自动回退旧镜像。

### WEB-17 · 直接粘贴导入

- 不自动读取剪贴板、不在输入时发送请求；仅点“分析并继续”后才把内存文本包装成

- 复用现有账户能力、文件大小限制、导入目的地、解析预览与未知结果恢复；不新增

  清除草稿；不会持久化正文。
- 尚需用实际服务验证文件与粘贴的同源等价、失败保留、认证切换和超限体验。

### WEB-18 · 正文表格 TSV／CSV

- 从 ReactMarkdown 的完整 HAST 表格结构提取行、单元格和嵌套文字，不从 viewport
  DOM 采集，保留空单元格、前导零、数字/日期的原始文本和多行内容。
- 提供可选表头、TSV 剪贴板、UTF-8 BOM CSV 下载。默认将疑似公式单元格作为安全文本
  加单引号并显示计数；用户可显式关闭。超过 50,000 个单元格时完整显示表格但关闭
  导出并说明上限，不静默截断。剪贴板拒绝时显示可手动复制的选区。
- 编辑器自己的 source table tool 覆盖 renderer table handler，避免把导出按钮放进
  单元格编辑界面。
- 尚未使用真实浏览器与目标表格应用验证 TSV 换行导入及各软件的公式行为；安全说明
  不承诺所有电子表格软件完全一致。

## 离线包下载故障

已找到并修复一个可重放的服务端竞态：响应返回后到 FileResponse 打开／传输文件之间，
同包更新的提交后清理可能移除旧产物。新增 `offline_package_leases`（0056），
下载时锁定产物行并提交 90 秒租约，ASGI 响应每 15 秒续期，完成／发送失败／
取消后屏蔽取消地释放；禁用 pathsend，避免把实际传输交出租约生命周期。
提交后清理和全局候选扫描都排除仍有效的下载租约。过期不再保护文件。

`test_offline_download_leases.py` 的 6 条测试覆盖清理延后、过期、SQLite naive
时间戳、headers 到第一次文件读取间的更新清理、头／正文发送失败后的释放；
更精确 headers 竞态断言随最终 21 条 API 专项重跑通过。
这证明该竞态受保护，**不证明无请求状态／网络 trace 的原始用户故障一定由它导致**。
真实大包、慢网和当前设备仍需生产／用户侧脱敏证据；不改包 v1/v2/v3、
Dexie v2 或既有本机数据，也不降低下载权限／校验。
