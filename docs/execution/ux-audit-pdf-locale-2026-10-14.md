# PDF 查看器语言一致性修复（2026-10-14）

本批次按用户要求仅修改本地源码；不启动服务、不登录、不运行浏览器或脚本验收，不提交 CI，不部署。

- PDF 错误状态的重试按钮也跟随当前语言。
- 只增加显示层语言分支，不增加请求、轮询、渲染任务或内存占用。
