## 结论与优先级

已保存选择和失败恢复机制有效，但重复说明与规则按钮压缩了正文阅读区域。
每条候选都展开长期规则操作，用户难以快速区分本次删除与今后学习。
完成后旧选区及“扫描整个当前对话”仍显示在结果上方，主次与时间关系不清。
800px 左右的工作区被原样用于短结果，尤其手机用户容易误以为仍有内容未加载。
本轮保持原纸张/墨色风格，通过渐进展开和按内容收缩恢复阅读顺序。

## 设计约束（实施前）

沿用现有设计系统，不另建视觉语言。领域：对话、消息、片段、原文、新版本、
规则、审查、恢复。颜色世界：纸白、抬起的纸面、石墨、淡墨、海绿操作、琥珀
命中、克制红色故障，全部映射现有变量。特征：原文片段 → 明确选择 → 完整
差异 → 新版本，在候选摘要、展开上下文、选中态、预览和完成结果中保持一致。
默认全部展开的操作墙改为逐条展开；装饰卡片改为细分隔行；固定大成功页改为
短结果。不会以隐藏命中原文或自动选择来提高表面密度。

组件共用实施检查点：Intent 为准确判断片段且能找回已保存结果；Palette 沿用
纸/墨/海绿/琥珀/红色令牌；Depth 仅使用轻分隔与表面差异，阴影仅属全局弹窗；
Surfaces 使用 bg-page/surface/subtle；Typography 沿用应用字体，正文 text-sm、
身份/原因 text-xs，精确命中保留原字符；Spacing 为 4px 基准，12/16px 分组，
触摸与键盘操作至少44px。候选、结果、容器均遵守这些既有约定。

### 完成实现

- 候选默认展示全部精确命中、每侧最多64个Unicode字符的短上下文、原因、
  本地化角色和行号；多对话扫描直接显示来源标题。缩短与空白折叠只用于周围
  摘要，不改变精确命中、源码或位置；使用现有亮／暗色 mark 令牌突出命中。
- “上下文与规则”按候选展开完整上下文、已选项删除后的上下文和明确的个人
  例外／学习操作。44px按钮支持键盘和展开状态；普通保存刷新不丢展开状态，
  收起不改变决定。应用前仍必须预览完整消息差异。
- 已确认结果报告给原弹窗，内容高度及桌面宽度收缩；标题固定，结果体可滚动。
  隐藏旧选区、规则入口、扫描按钮及审查说明，结果获得焦点。预览不再重复
  显示“选择已保存”与同一次应用失败的第二条错误；规则页不混入审查读取状态。
- 不修改扫描、保护、选择／应用API、数据库或离线合同；前八批恢复逻辑保留。
