## 发现与处置优先级

### A01 · P1 · HTML AST 类型不闭合

- 证据：`apps/web/features/rich-markdown/remark-safe-html.ts:48–60`。
  `parseHtmlFragment` 返回 `HtmlNode[]`，却直接读取不在 `HtmlNode` 上的
  `tagName/properties`；也没有用判别联合保留“唯一根是 element”的类型证据。
- 影响：可导致 Web typecheck 失败；这是源码问题，不是已经观测到的 CI 失败。
- 调整：分开 mdast 与安全 hast 类型，直接选取已收窄的 element；不放宽白名单。
- 成本：小；用户侧需执行 typecheck 和富内容专项。

### A02 · P1 · 收藏恢复不可完整键盘操作，重试后残留旧提示

- 证据：`apps/web/features/reading/reading-list-button.tsx:77–96,145–167`。
  portal 在 body 末尾，打开时焦点仍在星标；Tab 到下一工具即触发外部关闭。
  原请求重试只吞 catch，不清理本地 error/open；重新读取也缺少账户/会话归属判断。
- 影响：键盘用户无法顺畅完成只读核对；成功后仍像未保存，可能诱发多余操作。
- 调整：仅在触发器仍拥有焦点时交接到面板；非模态、外部关闭不抢焦点；
  成功/拒绝/未知分别处理；迟到结果不能控制新会话或已关闭提示。
- 成本：中；需键盘、丢响应、重试拒绝、切换会话专项。

### A03 · P2 · 收藏/批注摘要越界页未回退

- 证据：`apps/web/components/collection-view.tsx:15–35`、
  `features/reading/reading-list-page.tsx:24–37`、
  `features/annotations/annotation-inbox-page.tsx:16–19`。
  URL offset 被保留，但成功摘要的 total 变小后没有夹取到有效页。
- 影响：末页最后一项移走后呈现误导空态；用户要手工找上一页。
- 调整：共用分页回退，只消费当前范围成功且已完成的读取；
  保留筛选、排序和正常返回位置，不在加载/失败时推测 total。
- 成本：小；需末页删除与并发减少专项。

### A04 · 撤回缺陷判断 · 手机帮助面板已有 CSS 兜底

- 证据：`apps/web/components/reader-keyboard-help.tsx:34`、
  `features/conversations/conversation-reader.tsx:3173`。
- 后续反证：`apps/web/app/globals.css:1262` 已对手机专注模式提供固定居中、
  受限宽度、底部安全区的定位覆盖；不能只看组件 class 就认定手机会裁切。
- 处置：**不重复改造现有面板，不把该项计入已修复缺陷。**
  可视视口缩放/短屏自动择位仍是未验证的增强边界；需要用户截图/浏览器证据
  再决定是否引入测量定位，保留现有外部关闭与非模态交互。

### A05 · P1 · 折叠定位仅认识旧 thinking

- 证据：`apps/web/features/conversations/reader-navigation.ts:88–94`。
  仅展开 `details.reader-thinking`，不覆盖新增 callout/details。
  正文目标自身也可能包含折叠后的摘录范围。
- 影响：搜索/批注能命中源内容，却可能因不可见后代而定位失败或偏移。
- 调整：沿真实目标及精确文本范围展开受支持的折叠祖先，再进行稳定对齐；
  不展开无关折叠，不新增 scrollTop 补偿。
- 成本：中；需嵌套折叠、同块多个折叠、精确摘录、取消导航验证。

### A06 · P2 · 键盘异步意图与工具焦点未完全协同

- 证据：`apps/web/features/conversations/conversation-reader.tsx:1730–1866`。
  待读目录只存在 ref，无可见 pending；返回时只检查阅读意图/账户，
  打开工具本身未必使该意图失效。
- 影响推断：等待期间打开帮助/编辑器，旧快捷键仍可能迟到跳转。
- 调整：显式退役旧请求、可见等待/取消，工具焦点和新滚动优先；
  继续保留真实 DOM 导航和同方向 repeat 合并。
- 成本：中；需延迟索引响应与新意图竞态专项。

### A07 · P2 · callout 换行位置误用下个节点

- 证据：`apps/web/features/rich-markdown/remark-reader-callouts.ts:44,88–109`。
  文本节点内标题/正文分割把下个强调/链接的 start 当作前面正文的 start。
- 影响：正文 source range 可倒置或跳过摘录，危及噪声保护与文本定位。
- 调整：从原文坐标计算换行后起点，无法取得精确位置时不伪造范围；
  增加 LF/CRLF、blockquote 前缀、强调链接组合用例。
- 成本：小至中；专项测试待用户运行。

### A08 · P2 · 离线空更新计划多一次无效确认

- 证据：`apps/web/lib/offline-downloads.ts:116–119,149–150`。
  inspect 已返回空 targets，仍请用户确认，然后必然抛空范围错误。
- 影响：用户批准操作后又“失败”；现有文案还可能把“无需更新”说成“没有可用对话”。
- 调整：空计划在确认之前退出并显示无需重新下载，保留已有副本。
- 成本：小；不改变旧包/Dexie schema/完成回执。

### A09 · P2 · 完成表述超出实现证据

- 证据：两份设计文件开头“计划范围的源码已实施”；
  `assistant-message-renderer.tsx:451–479` 只重算 margin，不执行覆盖并集；
  safe HTML 只解析单一、平衡的 HTML node。
- 影响：后续执行误以为缺段检测、通用分片 HTML、性能测量都已完成。
- 调整：明确主路径、局部修补、仍需实现、等待用户验收四类状态；
  不为宣称兼容而放开脚本/资源路径或清空测量缓存。
- 成本：小（文档）；剩余几何/性能工作为独立受控批次。

### A10 · P2 · 新增媒体渲染透传进可编辑表格

- 证据：`apps/web/features/conversations/markdown-renderer.tsx` 中
  `editableTablePreviewComponents` spread 普通正文组件，只覆盖链接和图片。
  安全 HTML 表格内的 audio/video 因而也会成为编辑单元格内的媒体控件。
- 影响推断：编辑点击可能触发播放控件和同源媒体请求，超出该工具的惰性预览合同。
- 调整：编辑预览中的音视频只显示惰性文字；正常正文播放不受影响。
  同时修正旧测试对安全 `section` 事件属性的断言：当前合同是去掉事件、
  保留允许的静态标签，而不是拒绝整个安全标签。
- 成本：小；新增真实共享渲染器规格，未执行。

## 应保留的设计

- 收藏仍沿用旧 collection/API/route 与 read/unread 数据，不做破坏迁移。
- 未知写入结果先只读核对；原请求重试复用身份，不自动重放。
- 富内容采用白名单和二次 sanitize，不载入第三方脚本或猜测本地附件身份。
- Reader/Share/Offline 共用正文渲染与真实 DOM 导航，不靠点击正文“治白屏”。
- 合成示例入口保持移除；性能收益不捏造数据。
