# 正文共享表格与紧凑行列编辑

2026-10-22（Asia/Shanghai）。用户先指出正文与工具预览不一致、缺少删列，再确认
“正文共享展示层 + 工具编辑扩展层”，随后反馈界面占位过多。本次是这一明确范围的
本地实现，不恢复无限优化目标，不提交、不启动 CI、不部署。

前置[调研](ux-audit-body-tables-2026-10-22.md)通过内置浏览器查看 BlockNote、
Milkdown、TOAST UI、Tiptap 的项目与官方资料。借鉴交互，不复制源码、不引入依赖、
不替换 CodeMirror 或 Markdown 解析器。

## 1. 实际实现

### 正文与工具共用展示

- `markdown-table.tsx` 提供轻量滚动容器、表格和单元格；正文与预览使用真实共享
  MarkdownRenderer/GFM/Math 链，不另造假表格。
- 普通正文保留源位置属性、对齐、表头、条纹、链接和图片政策；不常驻编辑器或按钮。
- 长单元格采用 28rem 上限，窄屏 18rem；说明文字可以换行，无法拆分的公式/代码
  在本单元格内滚动。多列内容仍可横向滚动，但不撑宽页面，不截断源 Markdown。
- 工具沿用其有界双轴滚动/分页，复用共享表格与单元格，不套第二层外部滚动容器。

### 全表结构命令

纯转换接口支持指定位置插行、插列、删行、删列。行号不含表头；删列同步修改表头、
全部数据行和对齐。分页仅限制预览，不限制操作范围；保留最后一列，允许零数据行。
前缀、CRLF、原范围保护和现有输入预算不变，超限拒绝而不截断。

点击/聚焦单元格确定当前行列；标题栏的菜单明确显示操作对象，打开后高亮对应区域，
菜单只包含前/后插入与删除。触屏单击可用，不依赖右键、长按或悬停。菜单位于
工具焦点范围内，支持方向键、Home/End、Escape 返回和 Tab 离开。

结构撤销最多保留八份不可变草稿，按序列化 UTF-8 大小合计限制到 2 MiB。
这不是实际 JS 堆上限，不复制整篇消息。后续单元格或 Markdown 编辑清空结构历史，
避免撤销结构时丢失更新的文字。取消不改源码；Apply 仍为原 CodeMirror 范围的一次
transaction，应用后可一次源码 Undo，不直接保存服务器。

### 对“占位置”的修订

| 最终选择 | 理由 | 拒绝的替代方案 |
| --- | --- | --- |
| 行、列菜单及撤销放入标题栏 | 内容区留给对照表格；目标由最近聚焦单元格确定 | 每格放按钮/留两侧空白；单独再加一整条工具栏 |
| 菜单中才展示插入/删除 | 减少常驻选项，又能明确知道删的是哪一行列 | 四边再加 `−`；保留多个“规范/加行/加列”模式 |
| 结构反馈放底栏短 live region | 删除可撤销且有反馈，不挤占独立一行 | 每次确认弹窗；常驻说明块 |
| 单元格最小宽度从 96px 降为 64px | 短内容与窄屏不必为控件预留空间 | 固定均分所有列；让长文字无限拉宽 |
| 小表 Markdown 初始 96px，可拖动调整 | 仍能直接双向编辑，不强迫占满 160px | 默认隐藏源码；固定高源码区 |
| 保留 44px 四边点击区域 | 不能用按钮盖住单元格/滚动条来换取紧凑 | 24px 边沟+44px按钮；缩小触摸目标 |

沿用项目纸面/石墨/海绿色 token、工作字体和 4px 间距尺度；不用新字体、品牌色、
装饰卡片或动画。标题先于内容，行列动作是次级、应用是底部主动作。窄屏去掉可见
菜单索引，但保留完整无障碍名称和实际命中目标，不删功能。

### 失败试验与修正

1. 初始新增状态区域让旧的笼统 `role=status` 定位产生歧义，改为独立 live region。
2. 标题栏新增可用行列菜单后，旧焦点环断言仍假设关闭按钮是第一个控件；按真实
   顺序验证首个菜单与 Apply 的双向 Tab 环。关闭仍是打开时的初始焦点。
3. 紧凑试验把四边间隔降为 24px，已有坐标/命中测试报告按钮覆盖单元格或滚动条。
   撤回该间隔修改，保留原测试及安全尺寸；通过合并工具栏、减少单元格按钮与源码
   初始高度实现减负。不能把失败试验截图作为最终界面或把它当优化成功。

## 3. 有意保留的边界

- Chrome gate 使用真实正文 renderer、工具、工作区和 CodeMirror；API、Next
  loader、assistant-ui 源码转发和无关 rich-view/cleanup 依赖显式适配。
  **不是**认证 Reader/Share/Offline 全链路、Safari/Firefox、真机或辅助技术验收。
- 正文组件被共享消费方复用，但未据此宣称全部阅读容器/锚点恢复已经端到端通过。
  当前只检查正常表格源位置 wrapper 保留，没有新导航动作。
- 没有新增性能 profile、服务 RSS、OOM 或生产资源测量，不把旧长任务标为解决。
- 正文精确直达编辑、展开查看、列宽持久化、拖拽重排、合并单元格不在此次实现中。
- 无新 dependency、migration、API/导出/离线/Dexie/Share URL 合同。
- 仅本地未提交；没有 CI、推送、镜像构建或部署。发布仍需新的明确授权。
- 原已 dirty 的 `tsconfig.tsbuildinfo` 在实施早期被增量类型检查重新生成，未重置、
  未纳入交付；最终非增量检查和构建未再次改动它。不清理其他任务资料。
