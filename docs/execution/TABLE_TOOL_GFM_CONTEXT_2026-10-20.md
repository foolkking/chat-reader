# 表格工具实际 GFM 上下文校验 — 2026-10-20

状态：本地修复已验证；持续优化目标活动、无 Token 预算上限。
不推送、不启动 CI、不部署。无新依赖、API、migration 或持久化协议变化。

## 问题与失败证据

前一阶段 75 专项、49 浏览器的绿灯并不覆盖以下实际工作区差异：

| 输入 | 完整原文实际预览 | 修复前工具 |
| --- | --- | --- |
| 根 `textarea` 内跨空行的表格文本 | 没有表格 | 一张表格、Apply 可用 |
| `textarea` 内的链接定义被外部表格引用 | 保留未解析的 `[label][hidden]` | 错误显示 `label` |
| 引用内普通 HTML 被空引用行结束后出现表格 | 一张合法表格 | 无预览、Apply 禁用 |

第三项是前一阶段新增 HTMLBlock 保护引入的合法表格误拒绝，不回避其回归性质。
引用内 textarea 原本已被拒绝；最初探针要求所有 textarea 变体可应用的错误假设
单独保留，不记为额外产品缺陷或成功测试。

扩充的正式浏览器基线在 **32** 场景通过后因第一项错误可应用而失败。实际库与
工作区四例诊断保留同一旧 bundle 的真实输出；未用后续源码哈希冒充旧门禁绑定。

## 实现

### 1. 复用现有渲染链，不再依赖编辑器 HTML 节点的近似语义

含 `<` 的冻结源码使用一次 `MarkdownTableSourceProbe`：

1. 使用现有公式和富文本显示投影。
2. 实际挂载 `ReactMarkdown` 与共享 remark 配置，使用其真实 GFM/数学语义。
3. 提取字面节点、实际引用定义的原始源码范围。
4. 在 HAST、KaTeX 和 DOM 生成前清空探针树。
5. 在提交后的 layout effect 回传结果，不在渲染时更新父状态。

没有直接调用 React 组件充当解析器，没有新增依赖、第二套 HTML/围栏扫描、
后台请求或全局 AST 缓存。探针不产生正文 DOM、外链或图片加载。

普通不含 `<` 的 Markdown 保持编辑器冻结树复用和仅到表头的独立回退。
含 `<` 是保守触发条件，不是另一套 HTML 检测算法。

### 2. 坐标、预算与失效

公式显示投影用分阶段编辑映射恢复源偏移，再组合现有富文本投影的映射。
800 组合输入核对输出与现有公式规范化完全相同，并验证后方锚点；另验
Unicode、CRLF、公式分隔空行和富文本包装之后的 HTML/定义原始范围。
这些解析视图不会进入 Markdown 序列化或应用事务。

独立预算：

- 原始源码不超过 1 MiB UTF-8；
- AST 遍历不超过 100,000 节点；
- 保留字面/定义范围合计不超过 8,192。

预算耗尽、缺少坐标或证明过期时不授权自动处理 HTML 上下文，提示完整选中
表格重试；不截断原文。初始 AST 的解析受输入大小约束，不宣称硬时间/堆内存
上限。合法的大文档仍可明确选中小表编辑，原文之外的内容完全保留。

结果绑定完整冻结源码，在单元格及 Markdown 双向编辑时复用，不重复解析全篇。
原编辑器变化会令草稿不可应用；显式刷新重新检查新快照。Apply 仍由原表单验证
当前修订、原文与精确范围，再创建一个可撤销的 CodeMirror transaction。

### 3. 引用投影

实际字面范围先在等长视图中被空白遮蔽，再复用 CodeMirror 提取原始 label/URL；
只接受实际 GFM 定义范围内的结果。由此避免 textarea 内部示例漏出，也避免
引用内旧 HTML 节点遮住后方真实定义。投影仍受 256 条、32 KiB 限制；
定义身份、URL 拼写和外部原文不改写。

### 4. 界面边界

保持已经批准的纸面/石墨/海绿色、现有字体、4px 间距及原四边 44px 控件。
只在初次校验时显示简短状态，在超限时给出完整选区恢复说明；没有新模式或
常驻解释。显式代码/HTML 示例编辑继续保留外层标记，不改变 `skipHtml`。
本轮没有进行完整 43 项界面或辅助技术认证，不用局部截图代替这种验收。
