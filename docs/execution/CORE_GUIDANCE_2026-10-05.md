用户选择方案 B，补充首次进入 Current/Index 显示简短指引、提醒仅统计未纳入 Index 的消息、尽量少打扰且可退出。本轮实施这一范围；上一轮 Skill 身份/克隆清理、管理员额度申请及求助闭环的完整审查仍是独立待实施事项，不以本轮引导宣称全部完成。生产版本未改变。

## 已实现

- 空白对话列表与帮助页提供自愿打开的三步快速入门；可关闭，可从帮助重开并进入真实导入。
- Current/Index 首次进入显示用途及三步操作。当前浏览器按账户记住已显示状态，不在每条对话重复自动展开。随时从“如何使用”重开。
- “准备维护”直接生成当前 Context 包，下载按个人首选解析的 Maintainer ZIP，复制对应请求。外部处理完回到既有整包/单文件更新流程；不自动执行或发送模型请求。
- 导出交付去掉独立 Skill 语言按钮，使用界面语言对应的既有首选解析。区分维护/接续下载，失败可重试，不静默换成另一个包。系统/个人管理中的 locale 身份迁移属于前述独立事项。
- 导出提示仅计算 Index 范围外的非空消息：100 条或 60,000 Unicode 字符。无 Index 时整个当前对话未索引；已有 Index 时计 segment 区间并集，重叠不重复、缺口不漏算。
- 只有属于当前对话且可对应的范围才给出数量。未知/其他对话/超界/对象读取失败不猜测。新保存 Index 的附加顺序摘要检测后续覆盖区插入/删除/重排；Current 单独保存不重置摘要。这不是语义校验，旧文件按声明范围计算。
- 提示可关闭或对该对话停用；进入指引也视为已响应。相同 Index 下一轮需再增加一个阈值量才重现；“如何使用”内可恢复停用的提醒。
- 导出→指引切换保留 Reader 内的导出选项和任务引用。离线启动资源增加系统 Maintainer；离线可准备材料，文件更新仍要求联网。没有缓存时明确显示不可下载 Skill，不阻止包下载。
- 导出结果同时绑定接续文件 generation 与 Reader 已知的对话 revision；更新 Current/Index 后重新生成，保留附件等选择，不继续提供更新前的包。文件状态读取失败提供重试；Raw-only 导出仍可选择。
- 新 API 遵循本人范围；普通账户不能读取他人统计。无数据库结构迁移，head 仍为 `20261003_0046`。
