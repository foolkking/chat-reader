## 批注实现约束

关闭面板后，组件仍用于正文高亮，不能清掉同一合法范围的已读批注。关闭应淘汰
面板的过期读取；切换会话／数据源／认证代次必须隔离缓存与回调。正文仍可在面板
关闭时创建书签／批注，成功后打开面板；不能用一个 closed 条件禁止合法创建。

Notebook 的成功写入也要淘汰先前读取。笔记尚未读到时，父级必须提供加载／失败
和重试入口，不能把 null 交给草稿视图后无限等待。冲突未知不等于零冲突；草稿
继续保留，依赖冲突状态的覆盖动作不得使用未知值。Offline getNotebook 首次会
创建占位，这是既有 repository 语义，不能把它泛称为纯 GET。

## 界面工作简报

读者正在看原文或整理笔记，恢复提示应靠近出错区域，只在需要行动时出现。沿用
现有文本、浅分隔线、纸面层级和海绿色操作，不新增成功通知或动画。批注正文为
第一层，读取失败和重试为第二层，技术诊断留在证据中。字体沿用应用栈，工作内容
text-sm、辅助说明 text-xs；4px 间距基准，新增恢复按钮采用现有按钮样式和 44px
目标。不重做主题，不建立装饰卡片或额外页面。此方向继承会话中已确认的 Web 设计。

## 本地实施与验收记录

五项发现均已有本地修复，未提交、未进入 CI、未部署：

- 三种读取独立发布和重试。合法同范围缓存可继续阅读；401/403/404 或离线锁定
  不保留对应资源。首次失败不冒充空列表。关闭保留已有正文高亮，正文书签创建仍可用。
- 读取按会话、repository、认证代次、本次打开及请求顺序隔离；已确认笔记写入淘汰
  旧读取。选择、弹出内容和导航反馈也带范围归属；旧导航不能关闭新面板。
- 笔记／冲突读取未知时保留本机草稿，阻止相关保存、加入笔记及删除；给出局部重试和
  返回批注入口，恢复读取不自动重做写入。等待草稿存储后的写入再次核对当前权限状态。
- 所有批量操作使用完整有效选择，显示隐藏数和查看／清除入口。仅切换当前可见项的
  全选／反选不会清掉隐藏选择；书签样式和重复引用分别显示适用数。删除确认后的目标
  仅限原先确认且仍存在的 ID，使用当前笔记 revision，不包含后来新增选择。
- CSV/TSV 保住第一行表头和原行序，在首个预算边界明确停下，保留前缀并提供原文入口。
  不再跳过宽行、不把后来的短数据行当表头。原文件和下载逻辑不变。

解析预算为 10,001 行（含表头）、256 列、50,000 格、每字段 4,096 UTF-16 单位、
扫描 2,097,152 UTF-16 单位；保留正常引号、转义、CRLF、多行及 BOM，截断不切半
Unicode surrogate pair。分页每页最多 50 行且不超过 2,000 数据格，列标题单独保留。
同一个 100×64 合成表格，实际 React 元素树由一次 6,400 个 td 降为每页 1,984 个 td。
这是有界工作量证据，**不是 CPU/RSS 降幅**；既有完整文本读取仍有 50 MiB 上限。

延续 ux-audit 的先取证顺序；interface-design 和 senior-designer 的约束用于保持
现有主题、失败提示靠近内容、44px 新操作和无成功 toast。未执行新界面渲染，不能
据此宣称视觉评分或可访问性全面通过。批量服务器写入仍沿用原有逐项及 revision 合同，
不是新原子事务，也未测浏览器实际调度和跨标签并发。
