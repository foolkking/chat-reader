## 2. 离线恢复 O

### 2.1 保留已有修复，不误称完成

沿用逐对话串行子任务、持久化目标/幂等键/游标、每个对话原子提交、
已成功部分可恢复，以及容量错误不无限重试。不要退回全量 JSON 字符串导入。
512/256/512 MiB 的压缩/单项展开/总展开预算不是内存上限。
超大单对话仍可能触发容量限制，必须明确告知，不伪装成“包损坏”。

### 2.2 明确区分失败对象

| 状态 | 用户看到 | 允许动作与结果 |
| --- | --- | --- |
| 下载包过期/被替换 | 下载链接已过期，已完成的对话已保留 | 重建当前子包，维持目标及已完成游标 |
| 冻结目标已删除/无访问权限 | 当前下载范围中有对话已不可用 | 停在该项；“重新核对下载范围”，不自动跳过后报全部成功 |
| 网络中断 | 更新已暂停，已完成 N/M | 恢复同一批次，不重复提交完成项 |
| 空间不足 | 本机空间不足，现有离线副本未删除 | 引导查看空间；用户处理后重试，不自动清理 |
| 包容量超限 | 此对话超过当前导入容量 | 保留旧副本，停止无效重试；提供错误类别，不暴露正文/ID |
| 校验/身份不符 | 校验失败，未替换此对话的离线副本 | 有界重新生成；持续失败保留诊断，不循环 |

“重新核对下载范围”读取最新可访问目录，显示范围增减数量及保留结果；
用户确认后在同一父记录建立新 attempt（递增 attemptRevision、更新幂等身份与
冻结目标），不新增假想的 superseded schema 状态；已完成可用副本参与最新计划
计算，不重复下载。空计划不进入确认、不重启批次，也不把旧不可用项冒充成功。
取消则原状态保留。
权限不可用与删除对普通用户用统一不可用说明，避免泄露存在性。
检查账号代次和旧批次租约；迟到回执不得进入另一账号或新批次。

### 2.3 验收

- **O1**：过期包恢复成功；不可用对话不再走同一无效 GONE 重试。
- **O2**：第 N 项中断、刷新、重新进入后继续；前 N−1 项和旧失败项副本均不丢。
- **O3**：旧失败全量记录的三个入口与 v1/v2/v3 读取均有回归；新旧游标不可混用。
- **O4**：精确最终 SHA 的 CI、真实 API/worker、部署及用户实际全范围更新分别验收。
  合成大 JSON 成功不替代真实 47 对话流程；低内存设备另记结果。

## 3. 收藏 F

### 3.1 语义、命名与入口

- 所有面向用户的“待读/稍后读/Reading list”改为“收藏/Favorites”，包括标题、
  空态、工具提示、辅助名称、命令面板、导航和错误说明。
- 内部 `reading-list` key、路由/API、集合身份不改；兼容旧入口和搜索关键词。
- 任意已有集合条目都是“已收藏”，包括旧 read 条目。阅读完成不取消收藏。
  集合页默认全部；保留已有已读/未读作为次级筛选，不把它们混成星标状态。
- 空心五角星表示未收藏，黄色实心表示已收藏；使用专用收藏色 token，
  不挪用或修改全局 warning。亮/暗主题分别验收，增加轮廓与 pressed 状态，
  不依赖黄色单独区分。沿用 Lucide，不引入品牌图标或图片资源。

### 3.2 布局合同

- 普通桌面：`搜索 → 收藏 → 其他操作`，搜索右侧紧邻一个星标，不增加第二个取消按钮。
- 窄屏：`侧栏 | 可截断标题 | 搜索 | 星标 | 更多`，主要控件 44px 触达。
  当前藏在“更多”里的搜索提升为直接入口；其他工具仍可从更多进入。
  320px 下标题让出空间、可截断，按钮不被挤小，不横向滚动，不增加第二层固定栏。
- 专注模式保留轻量操作：现有退出/帮助区按需露出搜索和收藏，顺序仍是搜索→星标；
  键盘聚焦时必须可见，触屏提供明确唤出入口，不能要求悬停或退出专注才能收藏。
  不因收藏切换改变正文宽度、顶栏高度或阅读位置。
- Share 不增加修改收藏的权限；离线 Reader 只有现有能力授权的动作，
  不凭同一图标假造已同步服务端的状态。

### 3.3 状态与恢复

`读取状态 → 未收藏/已收藏 → 保存中 → 确认状态`。
读状态未知时不显示成可靠的“未收藏”；失败给“无法读取收藏状态，重试”。
保存中阻止重复提交，焦点留在同一按钮；仅匹配的服务端回执更新确认状态。
明确失败恢复前态并可重试；超时/断网导致写入结果未知时先只读核对，不自动重放写入。
核对失败保留“状态待确认”，不报成功。切换账号/对话后废弃迟到反馈。
操作错误放在不推移正文的轻量状态区域；浮层必须适应窄屏且可关闭。
多个页面并发修改后以最新读取为准，不用旧的乐观快照覆盖新结果。

### 3.4 验收

- **F1**：旧 read/unread 条目、已有 URL、500 项上限与分页/过滤不丢数据。
- **F2**：鼠标/触屏/Enter/Space 均可切换，连续点击只产生当前有效请求；
  失败、未知结果、跨账号和多窗口回归，不留下永远禁用按钮。
- **F3**：320/375/768/1440px、200% 放大、长中文/英文标题、亮暗主题、
  普通/专注模式均满足顺序、44px 触达、焦点与不移位。
- **F4**：旧测试中“收藏按钮切换已读”的断言要改成新合同，同时保留集合页已读功能的测试；
  不能仅删除旧断言后认为通过。

## 4. 帮助与快捷键 K

### 4.1 帮助面板

统一 CircleHelp 图标与其他操作的大小/触达范围；保留中文/英文可访问名称。
删除用户指定句子“输入、中文组词、对话框和目录内不会触发正文快捷键。”
这是删冗余说明，不是取消输入、IME、对话框和原生控件保护。

面板为非模态说明层：点击问号开/关；点击外部关闭并让原点击继续生效；
Escape 只关闭最上层，键盘关闭后焦点回到问号；外部点击不抢回焦点。
焦点移出可关闭，不设置焦点陷阱。关闭按钮保持可见。
宽度与高度以可用视口为界，可翻转方向，短屏内部滚动，手机避开安全区和键盘。
打开其他弹层前关闭帮助，避免同次 Escape 连续关闭多层。
把不准确的“Tab 打开目录”改为原生焦点说明，不增加冗长段落。

### 4.2 阅读快捷键的确定语义

| 按键 | 行为 |
| --- | --- |
| ↑ / ↓ | 约三个当前正文计算行高；长按不堆积平滑动画；减少动态效果时直接滚动 |
| PageUp / PageDown / Space | 保留已有阅读翻页与原生控件优先规则 |
| Home / End | 当前整个对话的第一/最后一条消息；不是当前加载窗口边界，也不是侧栏第一个对话 |
| J / K | 阅读线附近真实消息的下一/上一条；遇加载边界解析索引后加载完整轮次 |

一个处理器拥有“保护条件 → 真实意图代次 → 解析 → 导航”的顺序，
不再靠两个 window keydown 监听器的注册先后保证正确性。
输入/编辑/IME、非空选择、对话框和菜单消费事件时不劫持。
原生按钮 Space/Enter 不被抢；关闭帮助后仅因焦点仍在普通工具按钮，
不应永久吃掉无冲突的 J/K 字母阅读指令。该区别须有真实焦点测试。

优先使用已加载且有效的消息/索引窗口；冷目标使用现有有界 dialogue-index，
不拉取完整对话消息。获得真实 message ID 后复用现有完整轮次导航和 DOM 对齐。
相邻目标以真实阅读线为准，不仅依赖可能滞后的 activeMessageId。
最后一条被删除或目标版本变化时重新核对边界一次，不无限重试。

连续输入采用最新有效意图优先：同向长按有界合并，反向/Home/End 废弃旧目标；
没有无限任务队列。用户滚动、页面/账号变化、进入编辑/弹层会退休旧导航。
pending/error 隶属于该请求与访问代次，旧 finally 不能清理新请求。
解析期间短状态可见但不重排正文；失败保留正文，提供重试，不只 set 一个不渲染的 state。
首尾无邻居时短暂提示“已到第一/最后一条”，不报告系统错误。

### 4.3 验收

- **K1**：外部点击、再次点击、Escape、Tab 离开、短屏关闭/焦点回归均通过。

## 5. 阅读几何和性能 R

### 5.1 先复现，再判因

源码确认两条不同链路：图片比例/前序消息高度会变；虚拟块的 scrollMargin
并非每次上游高度变化都更新。当前恢复只保证“有一个可见块”，会漏部分空白；
正文 pointerdown 恰好触发布局通知，与“点击才恢复”吻合，但仍是源码归因推断。
还须区分真实内容空白、故意保留的末尾空间、资源加载占位与错误虚拟 spacer。

### 5.2 最小修复设计

1. **尺寸预留**：可信附件/源 HTML width-height/已有 image_display_v1 提供比例；
   图片加载前建立相同布局盒，保留原图不强制裁切。未知比例使用稳定占位，
   加载/失败后只做必要的一次尺寸收敛。gallery 不把初始 720px 当成实测容器宽。
2. **坐标更新而非全量重测**：消息/容器高度、图片、字体、折叠、图表改变布局时，
   使用同一有界、按 scroll root 合并的 rAF 通知，更新受影响消息的绝对偏移。
   保留已测块尺寸；不要每次高度变化清空所有 virtualizer cache。
3. **修复覆盖范围**：在滚动和布局变化后核对当前应覆盖区间，识别上/下半屏缺失及
   内部间隙，不能只看第一/最后行跨度或“可见行数 > 0”。
   精确排除合法段落空隙、折叠隐藏内容和尾部阅读空间。
4. **同一锚点所有权**：记录变高之前的最近稳定真实 DOM 阅读锚点；
   不能等图片 onLoad 后再捕获所谓“变更前位置”。仅在用户意图未变化、未被
   导航/恢复租约占有时补偿；真实滚动立即优先，程序化补偿不写成用户位置。
5. **三路径一致**：普通块、元素滚动虚拟块、Share 的 window 虚拟块全部覆盖。
   不以取消虚拟化、全量挂载、无限 overscan、定时轮询或强制 click 作为修复。

富内容折叠/展开必须调用同一几何协议，不能新增另一套 scrollTop 补偿器。
展开/收起保留触发器可见位置；搜索定位到隐藏后代时先展开祖先、挂载后再真实定位。

### 5.3 验收

- **R1**：迟到图片位于视口上/内/下、比例已知/未知、损坏/离线、连续画廊时，
  静止阅读锚点不意外移动；有主动滚动时不反向拉回。
- **R2**：连续小步高速上下滚动（每步低于现有大跳阈值）、滚轮/触控/滚动条/
  快捷键及立即反向后，无需点击即可恢复完整可读区域。
- **R3**：断言实际可见行区间的并集、内部缺口、边界和重叠，不只要求一个块可见。
  容量/恢复用例不得把消息真实大留白及已知尾部空间当作失败。
- **R4**：保持现有容量合同：p95 frame ≤34ms，最长 long task ≤150ms，
  5 秒 long-task 总计 ≤250ms；原容量场景消息 ≤40、虚拟块 ≤120、
  滚动反向容差 ≤2 CSS px 等原断言不放宽。40 是该场景预算，不是全局窗口上限。
- **R5**：Reader/Share/Offline、亮暗主题、字体/宽度变化、慢资源、
  恢复/搜索/批注/折叠并发分别覆盖；记录精确候选与历史基线，不拼凑绿色结果。

### 6.2 批注收件箱 I：现有能力保留，补真实使用闭环

具体补强/验收方案：

1. **入口**：两个集合空态都指向真实最近阅读；有筛选无结果优先清除筛选，

- **I3**：旧/当前版本、失联、折叠内批注、离线保存后同步、结果未知核对不丢草稿或伪造定位。

### 6.3 系统性能 P：前端、数据与后台一起约束

- 前端复用 R 组与富内容预算，补首次加载、长任务、内存趋势和解析次数；
  不用“DOM 数少了”替代阅读流畅度，也不把浏览器堆字节当服务器 RSS。
- API 复测既有集合摘要/目录的有界查询计划、分页、取消与缓存隔离；
  历史合成 47/470 场景的 7 次查询是回归参照，不是现网 p95。
  新富内容资源按当前可见窗口批量解析，禁止每个链接/图片一次 N+1 请求。
- worker 保持单并发；逐对话离线包有界，重试不重做已完成项。
  新图像尺寸解析复用既有元数据/受控管线，不在正文请求临时解码所有图片。
- 先测同一候选的 API p50/p95、SQL 次数、worker 峰值 RSS、包耗时与失败率，
  使用合成/脱敏计数；有真实瓶颈再改查询或任务拆分，不预设“加缓存/并发”一定更快。
- **P1**：旧容量门不放宽，新富内容/集合/离线场景分别有基线、候选和资源上限证据。
- **P2**：无新 N+1、无后台重复任务、无持续读写泄漏；优化不能损坏权限/取消/缓存新鲜度。
  不在本轮执行压测，不把旧 CI 速度或清理磁盘收益冒充新优化效果。
