# 表格实时预览调度续查 — 2026-10-20

状态：本地持续优化；未启动 CI、未推送、未部署。使用合成表格，不访问服务或用户数据。

## 改动

证据显示，输入时同步解析 Markdown 并更新 GFM/KaTeX 表格预览会造成可见长任务。
工具现将编辑状态保持为紧急更新，富渲染使用 React `useDeferredValue`，允许快速
输入时跳过不必要的中间预览帧。预览显示 `aria-busy` 与短状态；Apply 在预览文本
未追上草稿、或最新渲染表格的行列结构未验证前保持禁用。文本框和网格数据仍实时
更新，最终 Apply 仍校验当前草稿并写入一次 CodeMirror transaction。

这没有把 Markdown 解析移出主线程，也没有声称消除大表长任务。测试没有证明
稳定的跨轮次性能改善，因此不增加 debounce 延迟、不降低数据能力；继续保留
“预览实时追赶”语义。
