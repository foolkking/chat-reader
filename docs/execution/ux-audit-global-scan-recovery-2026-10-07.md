本批优先全局扫描请求生命周期，保留完整个人／管理员噪声能力目标。新显式扫描
需要重新检查当前对话和规则；同一请求重试必须固定在原任务，即使来源后来变化。
不把不同用户或不同明确请求合并。原无请求标识客户端保持兼容；共享任务中心、
单并发 worker、默认 KEEP、归档排除和正文真值不变。

## 基线与实施

API 基线在同一请求标识的两次提交间增加合成对话的来源 revision，实际得到不同
扫描 ID；预期相同任务断言失败（1 failed，另一未来用例 deselected）。原始 XML
只在本批临时目录，保留聚合摘要。浏览器 `global-scan-baseline` 同样得到预期失败：
真实后台任务已创建，pending GET 被延迟，按钮仍为排队中且没有确认／任务入口。
合成截图已检查。两项均为真实复现；未对真实对话或线上任务进行故障注入。

复用 BackgroundJob 幂等字段；同账户／同 UUID 的 PostgreSQL 事务锁保护查找和
创建。已记录任务优先于当前来源快照；终态记录仍可只读核对。新明确请求重新
检查当前内容与个人例外，旧无 header 调用保留兼容，不再以模糊最近任务推断
某次提交成功。没有新增 migration、任务类型或 worker。

界面把确认与后台读取分开，未知结果保留请求键并提供只读核对；缺任务时用户
明确重发同一个请求。当前账户 sessionStorage 只存 UUID；刷新重入不自动提交。
请求取消／20 秒截止和账户代际保护沿用现有设施。任务入口关闭原设置／审查
弹层后打开共享任务中心；审查已关闭时不提供失效入口。

首轮 9 项浏览器通过。视觉复查发现“无启用规则”错误与旧缓存启用状态矛盾，
增加错误后的规则刷新，并验证用户启用一条后可以完成扫描。未知结果说明去除
重复句子。增加从审查内部规则库发起新扫描并返回任务中心的用例，最终共10例。
键盘验收检查关闭原弹层后焦点仍位于任务中心。

整合 `global-scan-delivery` 实跑56例：53通过，3个宽度均复现焦点交接失败。
关闭设置的延迟恢复会在任务中心已经取得焦点后重新聚焦原入口。此项为
Observed(runtime)／High：鼠标可点但键盘焦点逃出当前模态。修复共享恢复逻辑：
有其他可见模态时，只向该层内部恢复；外部旧入口不得夺走新模态焦点。
普通关闭与嵌套确认仍恢复逻辑入口。保留失败gate，补测相关弹窗路径。

修复后 lint、非增量 TypeScript 与 build 通过。首次67例扩展重跑启动时 API
连接拒绝：隔离 supervisor 已因C盘短暂低于32MiB保护线停止，业务断言未能执行。
停止此失败测试进程；当前空间恢复约1GiB，确认隔离端口停止后仅恢复原测试
cluster，后续测试与构建不并行。不删除其他批次缓存，不调整全局临时目录。
