## 1. 用户角色

### 角色 A：本地资料拥有者（主角色）
- **身份：** 无登录，直接进入 `/`，主体 `local:default`。
- **权限：** 全部管理能力（导入、编辑、组织、批注、分享、导出、离线）。
- **使用频率：** 高频，长期使用。
- **设备：** 桌面为主，移动端辅助。

### 角色 B：Share 访客（次要角色）
- **身份：** 持有效 token URL，只读。
- **权限：** 受 scope（full/selected）和 options（include description/annotations/notebook、allow_export）限制；无 canonical 写。
- **使用频率：** 低频，一次性或短期。
- **设备：** 任意。

## 4. 三条主要进入 Reader 路径（D-009 混合路径）

改造后三条路径都优化，且相互衔接顺滑：

### 路径 1：列表驱动
`首页/Project 浏览列表 → 点击对话 → Reader`
- **优化点：** 列表项显示阅读进度、最近访问时间、摘要；hover 预览。

### 路径 2：搜索驱动
`Cmd+K 或侧栏搜索 → 输入关键词 → 结果（含上下文+高亮）→ Reader 精确定位`
- **优化点：** 结果显示匹配上下文、Project/角色标识、关键词高亮；点击精确定位到 block/offset。

### 路径 3：继续阅读驱动
`首页"最近"入口 / 移动端首屏卡片 → 一键进入上次位置`
- **优化点：** 保存/恢复阅读位置，显示进度，一键回到上次离开处。

### 路径衔接
- Reader 内可返回来源（列表/搜索结果），保持上下文。
- 搜索 → Reader → 返回搜索结果列表不丢失查询。

## 5. 场景差异

### 桌面 vs 移动（D-004, D-016）
| 能力 | 桌面 | 移动 |
|------|------|------|
| 阅读 | 完整 | 完整 |
| 导航（TOC/搜索/继续阅读） | 完整 | 完整 |
| 创建批注 | 完整（5 类型 4 颜色） | 简化（highlight/underline/comment，简化选色） |
| 精选笔记编辑 | 完整 | 只读查看 |
| 编辑消息/版本 | 完整 | 不支持 |
| 合并/拆分/批量 | 完整 | 不支持 |
| 导入 | 完整 | 不支持 |
| 分享 | 完整 | 基础（生成链接） |
| 导出 | 完整 | 基础（Markdown/.cr） |
| Project 管理 | 完整 | 单个移动，不批量 |

### 本地拥有者 vs Share 访客
| 能力 | 拥有者 | 访客 |
|------|--------|------|
| 阅读 | 全部 | 授权 scope 内 |
| TOC/局部搜索 | 全部 | 授权范围 |
| 批注/编辑/管理 | 全部 | 无 |
| 导出 | 全部 | 仅当 allow_export |
| 私有内容（description/annotations/notebook） | 全部 | 仅当对应 include flag 开启 |

### 在线 vs 离线
| 能力 | 在线 | 离线 |
|------|------|------|
| 阅读/搜索/TOC | 全部 | 已下载资料 |
| 批注/笔记写 | 直接写 | 写 outbox，联网同步 |
| canonical 管理 | 全部 | 禁用/隐藏 |
| 阅读位置 | 服务器 + 本地 | 本地，联网时本地较新不被覆盖 |
