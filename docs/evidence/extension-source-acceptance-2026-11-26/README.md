## 已复现的失败与修复

| 复现 | 根因与处理 |
|---|---|
| 默认全选后选第 11–13 轮，结果仍是全选 | 原逻辑只向 Set 添加。现在先验证范围，再替换／加入／排除；非法操作不清空原勾选。 |
| 两种解析器对同一分页快照，在无时间或并列时间时输出顺序不同；请求标记变化也报“对话已改变” | 原流式路径保留先到的新页位置；两端都按整个对象序列化串比较。现按实际页序/页内顺序保留首次记录；只豁免可验证的非语义差异，正文、嵌套附件、包装层父节点和未知字段冲突仍失败。另修字节路径跳过无 ID 可见消息。**没有证据把用户原失败归为上述原因。** |
| 来源在同一阶段第二次更新后立即抛错，末次测量未发给后台 | 捕获端在关闭端口前冲刷，发送受限诊断；后台清理封包前草稿、保留阶段和统计。异常正文、文件名或地址不进诊断。浏览器硬消失仍只能保留此前已到达后台的测量。 |
| 来源有章节但渲染为独立文字块或只在 DOM 有章名；历史持续逼近仍被 12 秒整段截断 | 只在身份一致、可定位的结构或唯一文字范围上确认。改为“无进展预算＋总上限”；改进中间版还复现边界重复探测、暂停动画帧时旧测试进程停住，保留失败并终止该测试子进程；修复定时器与边界逻辑后按原断言全量通过。 |
