# 用户浏览器验收单

**只在你授权的测试账号、对话和 Reader 测试实例中操作。不要上传进生产，也不用发送密码、Cookie、token、真实对话链接或正文。** 本轮没有用自动化代你完成下表，没有用旧截图冒充新包实测。

### 先确认你测的是哪一套

1. 对实际下载的 ZIP 运行 `Get-FileHash -Algorithm SHA256 <ZIP路径>`，与[候选表](README.md#版本与安装包)核对。在独立测试浏览器配置加载该解压目录，刷新正在测试的来源页，不替换生产浏览器的同 ID 安装。仅看 0.3.0 不够。
2. 此次交付包绑定 `http://127.0.0.1:28080`；验收脚本创建的短命测试服务已关闭。若你用另一个测试域名，需要为**该准确 origin**另行构建、校验；不用提供任何登录信息。不要手改包、转发到现网或扩大权限。
3. 核对测试实例 Web、API、worker 的版本及 migration，配对后核实范围能力 `selective_append_ranges`。未启用新版能力时超过 250 应明确阻止，不可截断或偷偷分拆。先选之前失败、允许重试的测试样本，避免测试重复操作影响真实库。

### 执行与判定

| 代号 | 操作 | 可以记为通过的条件 |
|---|---|---|
| A 原失败 / B 短对话 | 在原导出器与 Reader 选同一可见分支；对照角色、消息身份与顺序、正文/静态表示、附件和资源。明确选测试项目再保存，在 Reader 打开最终任务和保存结果 | **最终 committed** 且规范正文、顺序、附件可访问或明确记录缺失，目标项目正确；仅“上传完”“已接收”“已预览”均不算。预期完整的样本出现缺件，记“部分”，不记通过 |
| C 超过 100 轮 / D 含分页的超长对话 | 记总轮数与起始位置；用提纲尾→首、首→尾、末端→中间历史，再返回。期间另测主动滚动取消 | 每次确实看到所选消息及其上下文，历史加载、列表稳定后仍在目标。只变高亮、停在同名邻居、窗口回弹或显示“位置未确认”都不算成功；取消后不应晚到滚动 |
| E 长 DIL 回答 | 同一回答分别点二级、三级章节；有重名时分别尝试。另测只有静态回退或无法唯一确认的章节 | 可确认的命中应显示具体标题/章节文字且稳定；不确定应明确失败而不是退到消息开头并报成功。静态 DIL 不是可执行交互，也不等同完整动态状态 |
| F 图片和文件 | 对照原导出器和来源页的文件数、名称/大小、实际可读字节。可以在测试机本地对同一文件算 SHA-256，不必回传哈希。再用已知缺资源的授权样本观察提示 | 应有的附件可打开且内容相符；不可取的资源有准确缺失数/提示，只有明确同意时才认部分保存 |
| G 历史编辑分支 | 在分叉前、后分别读取；在一次读取或跳转中切换分支 | 旧操作停止或明确未核实，不把隐藏消息或相邻分支混入本次顺序；显式重读后只处理当前分支 |
| H 追加与诊断 | 默认全选直接选轮次 11–13，再加入、排除、跨页、按角色及 Shift 勾选；试 >250 条，经 Reader 核对后提交。另做一次用户取消 | 范围实际变化；最终新增/跳过与选择对应、原目标前缀不变。取消或来源中断保留最后已传送计数/阶段，未封包不能“续传”或显示成功 |
| I 项目 | 核对已显示目录与实际项目列表，手动翻页/展开后刷新，记录发现条目数；映射已有项目或在 Reader 确认同名新建 | 只选择有证据的成员，未知/冲突不猜；创建仅回填对应行，尚未触发导入。局部目录即使碰巧与当前账号数量相同也不等于提供全账号合同 |

**仅选用已有材料的离线对照（可选）。** 若已合法持有该对话的单独 JSON 树，或**同一对话**从新到旧的完整分页快照，可以在本地运行：

```text
node scripts/extension-beta/offline-source-parity.cjs <已验证的解压目录> tree <单个对话.json>
node scripts/extension-beta/offline-source-parity.cjs <已验证的解压目录> pages <最新页.json> <更早页.json> …
```

不要提供完整账号导出、浏览器配置或网络会话记录；拿不到独立快照就把该项记为未验。工具不联网、不写文件，仅核对候选中五个固定模块并比较输入快照的完整 JSON / 字节范围解析。原解析器需在内存中解析该对话；身份不明、缺少声明的下一页或提供多余页时不会通过。即使两种输出一致，**仅靠这些文件不能证明用户交齐了所有中间页**。输出仅固定原因、计数、相等/不等；默认使用快照 `current_node`，不证明网页上显示的分支。`parity:true` 也不代表已下载资源、已写入 Reader 或历史浏览器版原导出器的所有渲染结果相同。

**建议回传的最小信息：** 样本代号、包摘要前 12 位、测试实例版本、操作、预期与实得计数、终态（含 partial）、具体未命中的跳转或有限错误码。任务编号可在自己的测试机保留；回传时用代号。截图可留三张：实际插件选区、跳转后的目标与提纲、Reader 最终回执；**先遮挡**地址栏、账号、项目/对话名、正文、ID、文件名和所有凭据。不能安全遮挡就只回传计数和判定。
