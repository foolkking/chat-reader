# 侧栏与管理员在线升级：隔离验收（2026-11-18）

这里记录工作树，而不是生产上线或 GitHub 实发回执。基线为 `26b35501`；界面前后使用相同的生产依赖与构建方式（Next 16.4.5），全部内容来自合成夹具。

## 界面

5 个宽度 × 中英两种语言 × 排序、收起、左下设置 3 个状态 × 修改前后，共 [60 张截图](sidebar/)。例如：224px 的[排序前](sidebar/before-zh-CN-224-sort.png)和[排序后](sidebar/after-zh-CN-224-sort.png)、[设置前](sidebar/before-zh-CN-224-settings.png)和[设置后](sidebar/after-zh-CN-224-settings.png)、[折叠后](sidebar/after-zh-CN-224-collapsed.png)。

- 桌面栏 224/288/448px、手机视口 320/375px：检查按钮和弹层边界、点击区域、键盘选择/关闭/焦点返回、折叠后对齐、全局搜索及设置里的四个排序范围。
- 手机首页提供最近记录；主侧栏不显示“最近”，手机及桌面的快捷操作仍可打开它。普通用户设置不显示版本或运行状态，不请求升级接口。
- 独立 API/PostgreSQL 上用真实浏览器拖入项目和折叠的未归类目标，重载后核对归属；桌面、手机修改导航顺序及排序后读取 API 并重载核对。验收中发现隐藏侧栏仍重复注册拖放目标，已改为共享一个侧栏树。还发现一次测试副本残留旧面板；修正同步范围并重新构建、重复核验，未把旧副本截图计为通过。

## 升级、保全与速度

独立 Linux/amd64、Docker 27.5.1、PostgreSQL 16、Nginx TLS、真实浏览器，测试签名和两套实际镜像。浏览器从根管理员的**运行状态**进入：准备 → 确认 → 停服期间刷新同源只读进度页 → 恢复健康 → 兼容回滚。没有把服务 Redis/HTTP 模拟当作数据库或容器。分发端为隔离的 GitHub API 协议夹具，**不是** GitHub 或 GHCR 公/私网验证。
