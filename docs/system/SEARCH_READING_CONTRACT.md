# 搜索与阅读的边界

本轮源码合同（2026-11-20）。生产版本以 `PROJECT_STATE.md` 的精确发布回执为准；
本文件不证明候选已发布。调查先于修改，见[问题表](../evidence/search-reading-2026-11-20/ux-audit.md)。

## 查找与返回

- 全局、侧栏及一起阅读选择器保留原相关性搜索；单对话查找按正文阅读顺序字面匹配。
  侧栏不增加范围行。全局状态 `all` 是有效筛选，有对应的移除按钮。
- 全局标题打开对话，上下文片段定位原文。通过结果进入阅读或连续阅读前，将查询范围内
  已加载页的引用、页游标、选中项、命中展开项和列表位置放在现有 React Query 临时缓存。
  身份代次、用户与完整条件隔离；账户切换由既有 AuthBoundary 清空缓存。
  不将正文写入 URL、localStorage 或持久化搜索历史。过期或刷新后的缓存不是离线结果快照。
- 未选择对话时没有批量归档操作；无可用连续阅读队列时不显示空工具条。
  连续阅读放在结果之后，不在续页获得资格时插入结果上方、移动已有命中。
  保存搜索保留入口和操作恢复，列表按需展开；同步与容量说明在保存时显示。
- 已保存搜索为独立读取。收起时加载提示仍可由读屏读取，但不占新行；失败在原保存按钮位置提供重试。
  展开后显示完整状态或恢复动作。读取晚于续页时，不能把已选命中从静止指针下移开。
- 手机为非模态查找条，上一处、下一处、匹配位置、关闭常驻，结果与筛选按需展开。
  输入、中文选词和候选浏览不导航正文。明确激活才调用定位；成功后收起结果并释放输入焦点，
  查找条保留。关闭只恢复焦点，不回放旧滚动位置。桌面保留侧面板。
  手机关闭按钮、输入内 Escape 和正文获焦后 Escape 使用同一关闭路径；
  清除旧定位目标，`preventScroll` 恢复可见的原按钮，无按钮时才回到正文。
- 匹配计数与结果条数分开；`+` 表示尚有未加载的匹配，不冒充精确总数。
  结果列表只移动自己的滚动容器。程序定位、请求退役、版本变化与失效坐标继续执行原检查。
- 离线目录使用现有 Worker 中的文档引用检索中文句中片段和代码标识符，80 条一页，
  单条前瞻判断是否还有结果；摘要围绕真实命中。检索不读取媒体 Blob。
  对话内每批至多返回单文档 100 处，通过追加的文档身份及匹配游标继续读取，
  不取消上限、不复制全库正文。没有精确坐标的旧包只定位消息。

## 独立分享权限

只读 `POST /api/shared/{token}/find` 使用已有分享权限服务，**不调用个人全文索引**：

- live：仅当前获准消息的规范 RenderBlock；按 32 条消息分批读取。
- frozen：只读原快照，快照缺失失败关闭；不回退到后来编辑的源正文。
- 每次请求（包括后续页）重新检查密码解锁、过期、撤销与授权范围；
  不接受任意对话、路径或下载地址，不搜索私人批注、笔记和附件。
- 请求参数为 `q`, `limit`（1–50）, `offset`, `match_offset`, `match_document_id`，
  正文类型和角色。未知字段拒绝。延续长消息时验证文档身份；内容变化需重新查找。
- 返回 `no-store`；前端按分享访问实例隔离，关闭后不保留查询缓存。
  请求失败不继续显示缓存命中或允许旧候选导航。原公开链接、密码、导出及定位合同不变。

管理员只读搜索仍走独立管理员 API 与审计，不借用个人或分享授权；
输入法未确认时不提交，搜索失败不再展示旧响应。晚到的只读导航不能覆盖新手势。

## 谁能移动正文

| 路径 | 权威与取消条件 |
| --- | --- |
| Reader、Share、Offline 主动定位及书签恢复 | 真实 DOM 锚点、`reader-navigation` 容器所有权；新输入退役旧恢复；缓存首窗已被操作后，迟到书签不再改查询键或活动消息 |
| 翻页、回收及折叠 | 原完整轮次、窗口代次和布局确认；保持既有受限短对话前缀及虚拟化，不延时禁滚 |
| 图片、公式、字体、代码及表格尺寸变化 | 每个物理滚动容器共享 `reading-viewport`；只修正真实锚点位移，减去已经发生的用户滚动 |
| 消息刷新、任务勾选、版本切换 | 不在 `onChanged` 完成后再次 `scrollBy` 恢复旧坐标；使用同一几何所有者 |
| 搜索高亮及虚拟行重挂载 | 只重绘规范范围，不固定行、不聚焦、不滚动；观察仅限目标块 |
| 图片查看器及偏好面板 | 保留已有锁定、返回与焦点取消合同；Viewer 位移不冒充阅读书签 |
| Compare / Together | 两栏分别拥有容器、输入意图、导航与保存；列表滚动不移动另一栏 |
| 管理员只读页 | 只在显式选中消息后定位实际节点，不保存用户书签；新手势可取消待执行导航 |

**不能归结为图片一个原因：**已观察到正文高度不变时，旧消息刷新回调将
原生滚轮 800→1040 或 800→680 拉回 800。修复该竞争写入不等于排除所有设备渲染问题。

精确 SHA 完整 CI、签名产物、容量及可恢复备份全过才能发布部署，不在生产演练。
