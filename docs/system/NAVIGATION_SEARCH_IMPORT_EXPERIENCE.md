## 单条对话内查找（2026-11-20，本地工作树）

- 在打开的正文点放大镜，或在非输入框按 `/`、`Ctrl+F` / `Cmd+F`。已打开某条对话的离线资料库也走这条路径。`Ctrl/Cmd+K` 仍是全局搜索，不把侧栏或资料库目录搜索悄悄改成局部搜索。
- 默认按对话内的阅读顺序找正文。服务端查找只接受一条有权限的对话，包括归档对话；中文句中的片段和标点按字面匹配，词间连续空白可等价。不会用复制的标题、角色、跨正文块拼接的词或单独一个词冒充整句命中。可改看代码、章节、附件或批注；后两者打开文件或既有批注锚点，不伪造正文高亮。
- `↑/↓` 只移动列表选中项，不滚正文；点击或 `Enter` 才定位。正文可切换前后匹配，手机默认使用非模态查找条，结果与筛选按需展开，定位后仍可继续查找。输入及中文选词不导航。选择身份绑定实际消息版本、块与字符范围，不绑定重建时会改变的索引行 ID；已改动的目标不按旧行号偷换。虚拟行卸载不钉住正文，重新出现时重建文字高亮。
- 每页最多 50 条索引文档，面板每组最多挂载 50 个定位项。每文档每批最多 100 处，新增文档身份和匹配游标，允许访问第 101 处及后续匹配而不取消上限。离线先由 Worker 按当前对话和筛选取候选，再用实际块逐批核对；续页区分候选位置和有效结果数，有下一页时不报告精确总数。目录另以 80 条分页并给出实际命中摘要。老包确无块数据时仍可定位到消息，不虚构字符偏移。查找不读取媒体 Blob，不更改 Dexie 或离线包版本。
- 长代码块的字面查找只为实际命中换算原文坐标，不为每个字符构造坐标表。服务端与离线端沿用各自的大小写规则，不承诺跨语言、数据库排序规则的全文检索等价。全局相关性、分词及全局链接维持原合同。

### 历史CI 44135067562失败后的修复：并发排序与重连

- 两个携同一版本的排序写入只能有一个成功。胜者在同一事务中刷新、取得结果版本，
  然后提交；另一事务随后取得偏好锁，不会使已提交的胜者收到 409。
- 项目元数据失败不阻止读列表，但禁止修改项目排序。成功的 PATCH 只合并排序与修订号；
  不回滚较新的缓存修订，不等待无关刷新，也不跨账户写缓存。
- 侧栏项目、未归类、展开的项目分支和主列表在浏览器重连时主动读取。
  先确认已保存排序的读取成功，再模拟断网；同一查询刷新失败保持原链接、焦点和
  DOM 身份，只重试所属查询。没有可显示的旧行或无访问权限时，不声称仍显示上次内容。
- CI 分片、测试身份、跳过和超时不变。依赖门禁独立见
  [发布基线](RELEASE_SAFETY_BASELINE.md#dependency-policy)；以前的运行记录保留在下文。
- [本地验证记录](../evidence/navigation-search-import-2026-11-17/ci-44135067562-local-repair.json)：
  独立 PG 测试 4 项；隔离整站的 12 个受影响用例各运行两次，24 次通过，无跳过或重试。

## 导入：先辨认本批，再决定处理

- 新建导入仅显示待处理批次数入口；历史批次进入已有任务中心。
  批次行显示本次文件名、目标项目、最后活动和状态；创建时间折叠。
  分析／正式导入任务归入所属批次，保留原任务操作，不重复计数。
- 概览主标题来自本次来源文件；格式名称只是辅助信息。支持项可展开
  本次来源与正文节选。单来源不重复列文件名，零项状态不占空间。
  错误卡片同样只显示一次单来源名；没有已匹配格式时不显示“使用的导入格式”。
- `source_preview.py`在分析时写有界sidecar：最多12条消息，每条2000字符，
  标题2000字符，整个文件最多160,000字节。读取验证摘要，不重新解析ZIP。
- 身份绑定会话、分组、格式版本、来源指纹、artifact SHA／版本以及ZIP父包、
  member和路径。错批次、被替换来源、篡改sidecar返回冲突；旧批次无预览需
  用户明确重建。缺少批次版本时提示重新打开，不发送无版本读取或无限加载。
  保存格式不保存或复用上一批正文。A/B/C的JSON与同名ZIP已实际提交并读取
  canonical消息版本验证隔离，不只检查预览名称。
- 停止并保留沿用任务取消；放弃则先停执行，再清理本批暂存来源和草稿。
  已导入对话、保存格式不删除。关闭窗口不等于取消。
- 请求接受不等于停止完成。前端按账户／批次保存最小操作状态，未知结果只读核对，
  不重复提交；清理失败仍可见，只允许对应清理重试。正式导入停止保留原服务端限制。
  本轮不主动清理用户已有批次。

## 排序：按范围独立，置顶只分组

工作树侧栏修复（未宣称生产已更新）：项目和未归类共用标题/箭头；收起隐藏排序、数量、新建和列表间距，但未归类标题仍接收拖放。展开时使用紧凑排序按钮，菜单按实际侧栏宽度定位，不随整页宽度变成底部面板。字段和方向分别标出选中态，Escape 返回触发按钮，触屏目标不小于 44px。主列表排序未改变。

对话主列表中，用户打开批量操作后，即使稍后加载的账户偏好改变同一列表的排序，也不自动退出批量模式；旧顺序下勾选的项会清空，须重新选择。切换活动/归档、标签或账户仍退出选择。[竞态复现与 CI 记录](../evidence/online-update-2026-11-18/verification.md#batch-sort-review)。

优先级为范围→置顶／普通→所选规则→固定ID。不以置顶时间抢占手动顺序。

手动／名称／数量模式不展示无关时间。未归类不吸收归档项目内对话。

首次手动排序根据完整范围建立；自动／手动切换保留位置，新导入或移入追加到
可见尾部，包括兼容保留的反向手动顺序。
自动模式拖动先确认切换。重建旧手动顺序需独立确认，在排序菜单内操作。
