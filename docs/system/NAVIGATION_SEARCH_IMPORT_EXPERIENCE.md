## 导入：先辨认本批，再决定处理

- 新建导入仅显示待处理批次数入口；历史批次进入已有任务中心。
  批次行显示本次文件名、目标项目、最后活动和状态；创建时间折叠。
  分析／正式导入任务归入所属批次，保留原任务操作，不重复计数。
- 概览主标题来自本次来源文件；格式名称只是辅助信息。支持项可展开
  本次来源与正文节选。单来源不重复列文件名，零项状态不占空间。
- `source_preview.py`在分析时写有界sidecar：最多12条消息，每条2000字符，
  标题2000字符，整个文件最多160,000字节。读取验证摘要，不重新解析ZIP。
- 身份绑定会话、分组、格式版本、来源指纹、artifact SHA／版本以及ZIP父包、
  member和路径。错批次、被替换来源、篡改sidecar返回冲突；旧批次无预览需
  用户明确重建。缺少批次版本时提示重新打开，不发送无版本读取或无限加载。
  保存格式不保存或复用上一批正文。A/B/C的JSON与同名ZIP已实际提交并读取
  canonical消息版本验证隔离，不只检查预览名称。
- 停止并保留沿用任务取消；放弃则先停执行，再清理本批暂存来源和草稿。
  已导入对话、保存格式不删除。关闭窗口不等于取消。
- 请求接受不等于停止完成。前端按账户／批次保存最小操作状态，未知结果只读核对，
  不重复提交；清理失败仍可见，只允许对应清理重试。正式导入停止保留原服务端限制。
  本轮不主动清理用户已有批次。

## 排序：按范围独立，置顶只分组

| 范围 | 新账户默认 | 保存方式 |
| --- | --- | --- |
| 侧栏大区块 | 项目→未归类 | 账户偏好；折叠按账户／设备 |
| 项目之间 | 手动升序 | 原项目位置；选择器与侧栏同序 |
| 项目内对话默认 | 导入时间降序 | `navigation_sort.project_default` |
| 单个项目 | 跟随默认 | 可空`conversation_sort`覆盖＋`sort_revision` |
| 全部对话 | 内容更新降序 | `navigation_sort.all` |
| 未归类 | 导入时间降序 | `navigation_sort.unclassified` |
| 最近阅读／搜索 | 阅读时间／相关性 | 独立，不继承目录手动顺序 |

优先级为范围→置顶／普通→所选规则→固定ID。不以置顶时间抢占手动顺序。
内容时间采用`sort_time`，为空回退`imported_at`并标明；旧`updated`保留资料修改语义。
阅读、改名、移项目不改变内容时间。缺失其他时间显示“未记录”，不冒充“尚未阅读”。
手动／名称／数量模式不展示无关时间。未归类不吸收归档项目内对话。

首次手动排序根据完整范围建立；自动／手动切换保留位置，新导入或移入追加到
可见尾部，包括兼容保留的反向手动顺序。
自动模式拖动先确认切换。重建旧手动顺序需独立确认，在排序菜单内操作。
服务端基于完整元数据摘要校验版本和同置顶组相邻锚点，不接受部分页面覆盖全量。
并发变化、偏好／账户围栏或占用中的canonical写入返回409，不等待锁或
静默覆盖另一标签页。
关闭的项目分支、自动排序不预取完整手动顺序快照。

`0062`单head接续`0061`：独立未归类位置、导航偏好、项目覆盖和版本。
升级保留旧偏好与已有手动位置；推荐规则需用户主动应用，可恢复此前设置。
备份按现有列编解码保留新增字段，恢复补记手动顺序已初始化，避免切换模式重排。
没有改Share URL、`.cr`／离线包版本、Dexie或Reader真实DOM定位合同。

## 搜索：服务端先按对话分组

- `/api/search/conversations`在SQL分页前按对话选最佳命中；总数为对话数。
  同正文的不同对话均可发现。旧文档级接口保留，展开时按对话加载命中页。
- 标题精确→标题包含→真实内容相关性，最佳命中决定排名，不累加长对话命中量。
  标题匹配不能冒充每条消息正文命中。前端不按内容类型二次重排。
- 空格分词AND要求同一命中项包含全部词；双引号表示短语。
  `%`、`_`、路径和符号按字面匹配；保留PostgreSQL全文／trigram基础设施。
- 标题打开对话；片段保留原消息／批注／附件真实定位。结果顺序与键盘／连续阅读一致。
  范围、筛选、排序写URL和保存搜索；中文组合输入不提交，过期请求不覆盖当前结果。
  连续阅读返回链接保留所选搜索排序，并继续拒绝未知参数和重复参数。
- 仅页面代表项正文进入Python，展开后再取其他命中。
  600条合成文档／30对话，两页各10项只加载20个SearchDocument正文；查询计划与耗时
  留在本地证据。**没有生产性能提速或原内存预算通过的结论。**
